# VGSolar 双灯启动检查

更新：2026-11-13。板上可控红灯PD10、蓝灯PD11，低电平点亮；电源指示灯不参与。

- 初始化中：红灯约2Hz慢闪，蓝灯灭。
- 启动检查通过：红灯灭、蓝灯常亮。
- 检查失败：红灯约4Hz快闪、蓝灯灭，失败锁存到重启。

通过条件包括启动脚本到达完成钩子、TF挂载、机型选定、Commander/sensors运行及USB自动通信管理器启用。DMA/SDIO初始化或启动硬故障处理失败也会锁存失败。USB管理器异步等VBUS，蓝灯不证明QGC已连通，也不证明传感器校准、可以解锁或执行器正常。运行中拔TF卡检测不在此启动检查范围。

成功/失败路径均以前台等待保留初始NSH任务组，保护已有参数对象与串口生命周期。`boot_complete_wait`和`boot_failed_wait`仅供启动脚本使用，不在交互控制台手动执行。
