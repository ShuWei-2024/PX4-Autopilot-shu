# 编码器速度、米数与 QGC 显示

更新：2026-11-13。两路GPIO四边沿采集，默认每20ms发布原始状态；启用测量不会自动解锁或开启轮速闭环。

## 标定和启动

- `VGS_ENC_R_CPR` / `VGS_ENC_L_CPR`：右/左驱动轮一整圈的有效AB跳变数，包含传动比。默认0表示未标定。
- `VGS_ENC_R_REV` / `VGS_ENC_L_REV`：真实前进使原始计数减少时设置该侧反转。
- `VGS_WHL_RAD`：驱动轮有效半径，单位m；默认0。
- `VGS_WHL_CTRL`：速度反馈选择，显示速度不要求设为1。

任意一侧保存的CPR大于0时，板级脚本自动启动 `vgsolar_encoders`；两侧均未标定时可手动启动。默认值没有写入特定车辆的标定。

保持上锁、隔离执行器动力，确认左右映射和正反相序；以驱动轮为基准，重复测量一整圈的计数差，不把任意转动的累计值或铭牌PPR直接当作CPR。直接测驱动轮一圈后不再乘传动比。

历史机构齿数比电机:行走轮:编码器=5:4:3，若当前结构相同，编码器轴每圈有效计数乘4/3才是驱动轮CPR。半径0.0404m来自直径61.4+9.7+9.7=80.8mm的初始估算，需用实际距离标定。

## 状态和单位

```sh
vgsolar_encoders status
listener vgsolar_encoder_status -n 1
listener wheel_encoders -n 1
```

`wheel_encoders.wheel_speed`单位rad/s，右侧为索引0、左侧为索引1。原始计数不受CPR是否为0影响；速度换算需要有效CPR、正半径和有效采集。未配置、首帧未知时间间隔或停采时线速度为NaN。

速度按实际快照时间间隔换算，不是固定乘名义50Hz；未做低速平滑。

## QGC 查看

Analyze Tools → MAVLink检测 → `DEBUG_FLOAT_ARRAY`，确认 `name=VGS_ENC`、`array_id=1`：

- data[0]/[1]：右/左原始累计计数。
- data[2]：左右无效跳变总数；data[3]：采集活动标志。
- data[4]/[5]/[6]：右/左/两侧有符号均值，m/s。
- data[7]：两侧速度换算有效标志。
- data[8]/[9]/[10]：右/左/两侧均值的累计有符号行程，m。
- data[11]/[12]/[13]：右/左/两侧均值的累计履带路程，m。

同时发送 `NAMED_VALUE_FLOAT`：`ENCR_MPS`、`ENCL_MPS`、`ENCC_MPS`、`ENC_VALID`；行程 `ENCR_M`、`ENCL_M`、`ENCC_M`；路程 `ENCR_TRIP`、`ENCL_TRIP`、`ENC_TRIP`。选择数值右侧绘图即可实时查看，刷新率受MAVLink模式和带宽影响。

命名遥测在状态发布超过500ms、停采或换算无效时发NaN。`ENC_VALID=1`表示换算与发布有效，不证明编码器物理连接健康或无漏计。

## 行程、路程与清零

有符号行程按净计数累积，前进增加、倒退减少；路程按有效跳变逐边沿累积，正反都增加，包括同一发布周期内的往返。两侧均值不是GPS地速或起终点直线距离，原地转向也会增加平均履带路程。

停轮、保持上锁且动力隔离后，可重启采集清零：

```sh
vgsolar_encoders stop
vgsolar_encoders start
```

不要在使用编码器反馈控制运动时停启。重新启动或修改该侧CPR/方向、公共半径时，相应行程重新从零开始，未标定期间的运动不补算，米数不跨断电保存。

[11月13日实测](validation_20261113.md) 记录当前车辆临时CPR及约4.5%的左右差异。基础读数和静止有效零速已观察到，实车距离、速度精度、高速漏计和轮速闭环仍待验收。
