## 本轮已观察到的结果

### 参数存储

- TF卡独立备份完整解码1631字节，48项INT32、34项FLOAT。
- V5只修复FRAM多块源指针时仍保存失败；V6再关闭SPI2 DMA后，`param save`无报错，板载文件声明与解码均为1631字节。
- 重上电后CPR、方向、半径和超声波使能回读保持。底层DMA/缓存/时序机理与长期可靠性尚未进一步分离。
- 保存/恢复步骤及子模块来源见 [参数存储](parameter_storage.md)。

### 编码器及QGC

- 左右原始计数均有跳变，观察到无效跳变数0；不据此证明高速无漏计。
- 用户手转驱动轮一圈：右侧暂定CPR=22197，倒车正计数解释下REV=1；左侧计数-6912到-30115，暂定CPR=23203、REV=0。两侧相差约4.5%，需要重复测圈和真实前进方向确认。
- 半径暂用历史初值0.0404m。启用CPR后重上电自动采集，静止时速度/米数为有效零值。
- QGC已收到VGS_ENC和命名速度/行程消息。实际行走距离、速度准确性、左右对应与工作转速漏计仍需完整验收。
- 显示字段、单位与清零见 [编码器说明](ENCODER_QGC_SPEED.md)。

### 双超声波

- 原先两侧frames=0、右checksum停在14。串口改为工作队列内打开/配置/读/关后，帧数和字节增长，校验/半帧超时/I/O错误均为0。
- 目标从约0.52/0.55m变近时得到左63mm/右66mm。接好底板重新上电，仅查status得到左62mm/379帧、右66mm/381帧。
- VGS_RNG_EN=1已保存；该轮自启动与收数已观察到，尺量精度、逐侧对应和断线/恢复仍待验收。
- [串口诊断](DYP_UART_DIAGNOSTICS.md) 说明错误计数和无效距离语义。

### 负压、红外与电源

- PC0输入0.0956V，压力原始约+0.14kPa、滤波+0.15kPa，valid=1/status=2；若当时通大气，该值接近零表压。
- PB5 raw/debounced/blade_present均为1、sample_valid=1。用户表示这些输入此前已测，本轮未另附双状态机械到位和压力表精度对照。
- 用户确认电压已标定；备份BAT1_V_DIV=13.62，不能用参考默认20.65覆盖。电流按用户要求后续再测。
- 电池曾0%/紧急低电量，后续Normal/100%，变化原因未记录；不能将100%界面当作外部仪表证明。
- 曾有强磁干扰，后续界面Normal；动态航向仍未完成验收。重复 `get: param 65535 invalid` 尚未单独定位。

### 模式与输出

- CH5逻辑槽位1=Hold，2~5=Manual，6=External1。当前VGSolar注册mode_id=23，编号由Commander动态分配。
- 上锁Manual→VGSolar：active=True、state=STANDBY、速度0，motion_allowed和cleaner_output_permitted均False。
- 拨回Manual：nav_state=0、active=False，两项运动/清洁许可仍False；带运动命令退出后撤销旧请求尚未实测。
- 后续快照为nav_state=23、arming_state=1、usb_connected=False、pre_flight_checks_pass=True。曾出现解锁界面，不等于带动力动作验收。
- 用户给出轮距36cm，设置RD_WHEEL_TRACK=0.36并回读已保存；RO_MAX_THR_SPEED和RO_YAW_RATE_P仍0，控制器配置未完成。
- MAIN1/Channel0=Motor2左，MAIN2/Channel1=Motor1右；CA_R_REV=3，PWM_MAIN_REV=5（MAIN1和MAIN3反向）。MAIN3是RC AUX1直通，正常状态曾回读1881μs，不能因上锁就假设该通道无脉冲。
- 用户确认2BLD6010、PWM控制、1500μs中位停止。断开行走动力后执行 `actuator_test set -m 1 -v 0 -t 10`，驱动回读右Channel1=1500，其他通道0。
- 最后这条只验证驱动回读，不是物理波形或带电停止测试。

先上锁、隔离执行器动力，确认实际版本、参数和两项采集自启动。今天停止在右侧1500μs驱动回读，尚未确认10秒结束恢复无脉冲。

1. 断动力查看 `pwm_out status`，确认右Channel1回到0；必要时重做限时中位并检查超时。
2. 车架固定、履带完全离地，隔离左行走、滚刷、泵阀及升降机构，只接右电调动力，确保能直接断动力。保持上锁，仅测右侧限时1500μs和到时无脉冲两个阶段是否都停止。
